# 📦 Inventra ERP — Enterprise Resource Planning

**Inventra ERP** is a modern Inventory and Sales Management System designed to simplify business operations by managing products, categories, customers, suppliers, purchases, sales, and inventory in one centralized platform. It provides real-time business insights through an interactive dashboard, enabling organizations to monitor stock levels, track sales performance, analyze revenue, and make data-driven decisions.

---

## ✨ Features

- 🔐 **Cyber-Neon & Liquid Glass Auth Portal**: Dual-tab Sign In & Create Account, password strength meter, 1-click Fast Demo logins.
- ⚡ **Zero-Latency In-Memory Data Acceleration**: Millisecond response times with automated background PostgreSQL persistence.
- 📊 **Executive Business Dashboard**: Real-time sales charts, revenue metrics, low stock alarms, and transaction activity.
- 📦 **Full Product Management**: SKU generator, categorical filtering, stock tracking, and supplier mapping.
- 👥 **Customer & Supplier Directory**: Contact cards, transaction histories, and instant CRUD operations.
- 🛒 **Purchases & Sales Modules**: Automated inventory deductions, invoice generation, and audit logging.
- 📱 **Pinned Responsive UI**: Sticky sidebar navigation with permanent logout accessibility.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide React, Recharts, Axios
- **Backend**: Node.js, Express.js, JWT Authentication, Prisma ORM
- **Database**: PostgreSQL (Render Hosted)
